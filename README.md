# Exam Management App

Application de gestion d'examens, développée avec **Angular 19** et une API Node/Express.

![screenshot](./exam_app.png)

## ✨ Fonctionnalités

- Listing des examens
- Création d'un nouvel examenx
- Interface en Angular Material
- Tests unitaires configurés avec Jasmine et Karma

## 🧩 Stack technique

- **Frontend** : Angular 19 + Angular Material
- **Backend** : API Node.js/Express
- **Docker** : Docker et Docker Compose pour isoler les services

## 🚀 Lancer l'application

### En local

```bash
npm install
ng serve
```

# Docker Compose (développement)
```bash
docker compose -f docker-compose.dev.yml up
```
# Docker Compose (production)
```bash
docker compose up
```
